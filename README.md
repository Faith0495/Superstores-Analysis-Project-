# Superstore Sales Performance Dashboard

## Project Overview
This project was completed as part of the AnalystLab Africa Week 2 Business Intelligence assignment. It uses the Sample Superstore dataset to explore sales performance, profitability, customer segments, product categories, and regional trends through an interactive Power BI dashboard.

## Business Objective
To turn sales data into clear insights that support decisions about revenue growth, profitability, and business performance.

## Dataset and Tools
- **Dataset:** Sample - Superstore.csv (orders from 2014–2017)
- **Tools:** Power BI Desktop, Power Query, and DAX
- **Preparation:** Checked data quality and column types; formatted order and shipping dates, numeric fields, and postal codes.

## Key Performance Indicators
The dashboard includes five DAX measures:
- **Total Sales:** Sum of sales
- **Total Profit:** Sum of profit
- **Total Orders:** Distinct count of order IDs
- **Average Sales:** Total Sales divided by Total Orders
- **Profit Margin:** Total Profit divided by Total Sales

## Dashboard Features
The report examines sales by region, category, segment, and sub-category; profit by sub-category; and annual sales trends. It also includes an executive summary and interactive filters to explore the results.

## Project Files
- Power BI dashboard (`.pbix`)
- Dashboard export (`.pdf` or `.png`)
- Business Intelligence Overview Report
- Executive Summary Report

## How to View
Open the `.pbix` file in Power BI Desktop to use the interactive dashboard. The exported PDF or PNG provides a static view.
